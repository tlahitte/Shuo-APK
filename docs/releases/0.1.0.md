## Included

French-language offline phrasebook, 15 example phrases across ten categories,
search in Chinese/pinyin/French/English, favorites, recent history, phrase and
category editing, JSON import/export, themes, adjustable Chinese text, and
full-screen presentation with optional translation and 180° rotation.

See the [README](../../README.md) for installation, development, and signing.
The complete reviewed phrase library is still in development.

## Validation

- `:app:assembleRelease` and `:app:lintRelease` passed. Lint reports no errors;
  13 warnings recommend dependency updates.
- APK signature, package/version, minimum SDK, disabled debugging, and absence of
  Internet permission verified directly from the built artifact.
- Android 15 ARM64 emulator: clean install and first launch with airplane mode
  enabled and Wi-Fi/mobile data disabled. Fifteen example cards seed correctly.
- Signed APK smoke check: offline search, presentation, translation visibility,
  rotation, favorite changes, process-restart persistence, and reinstall
  persistence passed. No Shuo crash was recorded.
- Earlier application validation: 22 local tests, five instrumentation tests,
  and additional small-display/large-font scenarios passed. Those suites ran on
  the development variant; the signed APK has a separate manual smoke check.

Signature evidence: [release-signature.txt](../verification/release-signature.txt).
Physical-device testing and store publication have not been performed.
