from GitHub. Published as a signed Android APK on 2026-10-15.

## Changes

- The supplied sunset artwork is now the launcher icon, including adaptive icons.
- Exactly 310 workbook phrases ship on fresh installations, mapped to the ten
  existing categories. Chinese, pinyin and French are retained from the workbook.
- All 310 cards include English, Spanish and Italian translations. Navigation,
  category labels, forms, dialogs, accessibility labels and updater messages follow
  the selected language. French remains the default and the choice persists.
- Personal cards without the chosen translation fall back to French; custom
  category names remain as entered. Translation provenance and category mapping
  are documented in [the library notes](../library/README.md).
- Search uses a reusable normalized index and runs off the UI thread. It supports
  all four languages, Chinese, accent/tone-insensitive and joined pinyin. Startup
  reads the bundled JSON only when seeding/upgrading and waits for the first usable
  library/index before displaying card counts.
- GitHub update checks run after startup, at most once per day when the app is
  opened, and can be disabled. Categories → Updates provides a manual check.
  Downloads show progress and support cancel/retry. Android asks for installation
  permission when needed and requires confirmation; silent installation is not
  supported. The phrasebook remains fully usable offline.
- APK validation checks size, GitHub digest when available, package, version and
  signing certificate. Only HTTPS GitHub hosts are allowed. There is no embedded
  GitHub credential, and cards are never uploaded.

## Existing data

Room schema 1 migrates to schema 2. The bundled library upgrade is transactional
and refreshes unchanged built-ins while preserving edits, deliberately deleted
cards, favorites, history and custom categories. Three unmatched old examples are
retained and translated, so an unmodified 0.1.0 upgrade contains 313 cards.

JSON exports use format 2, with Spanish and Italian fields. Imports still accept
format 1. Version 0.1.0 cannot import format 2 exports. Export your cards before
uninstalling; automatic cloud backup remains disabled.

- 37 local tests passed: search, codec/import validation, repository operations,
  real schema-1 migration, built-in data preservation, all language fields,
  preference persistence, updater version/asset selection, caching/throttling,
  offline failures, cancel/retry, APK verification, length limits and redirects.
- Seven Android 15 emulator scenarios passed: CRUD/recreation,
  presentation/favorites/history/rotation, both themes, long Chinese, category
  management, all four languages including dialogs and updater labels, and
  simulated update download/cancel/retry/install-ready states.
- Release build and lint passed; lint has no errors. Remaining warnings concern
  dependency versions, plural fallbacks, icon variants and optional Kotlin helpers.
- APK v2 signature verified against the original release certificate; package,
  version, SDK levels and permission declarations inspected directly.
- Signed 0.1.0 → 0.2.0 installation succeeded on Android 15 in airplane mode:
  313 cards, changed favorite count and recent history preserved. Offline manual
  update check shows the localized network error; enabling Wi-Fi allows the public
  GitHub API check to complete successfully.
- Measured on the emulator for this signed upgrade: first frame 260 ms, fully drawn
  library 353 ms. Host JVM benchmark over the 310-card index: median 0.359 ms,
  p95 0.890 ms. These measurements are observations, not device-wide guarantees.
